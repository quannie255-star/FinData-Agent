findata 可信增强模块 · 接入面实测归档（v2.1.0，2026-09-17）
================================================================

定位：findata 不做通用 Agent 基座，作为「可信增强模块」挂载到
成熟 Agent 项目上。三个接入面：MCP 工具 / HTTP API / Python 服务层，
同一份 service 实现，不许两套口径。

── 3. 错误契约：未知指标带可用键（调用方可自愈）──
未知指标 stock_daily.ghost。可用指标：stock_daily.open, stock_daily.high, stock_daily.low, stock_daily.close, stock_daily.volume, stock_daily.amount, stock_daily.pct_chg, stock_daily.turnover, valuation_daily.p

── 4. HTTP API 同源实现 ──
GET /v1/trust?table=stock_daily&metric=close -> 200
（响应体与 MCP 工具逐字节一致 —— 一份 service，两份协议）
GET /v1/trust/board -> 200, badges=12

外部 Agent 集成契约（详见 docs/integration.md）：
  1. 会话开始调 trust_board 拿全板；
  2. 引用任何数字前查 trust_check，usable=false 不得作为已核验引用；
  3. 徽章与证据随答案一起返回给最终读者（芯片组件可嵌入 HTML）。
