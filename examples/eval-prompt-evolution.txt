语料说明
--------
base     ：7 类注入故障 + 5 个合法业务事件（既有标准语料，13 信号）。
extended ：base + 3 只标的的合法放量脉冲（×20、10 个交易日、量额同涨同换手），
           与 drift 故障（×20、仅放大 volume）构成探针比值同分布的混淆对：
           drift 故障实测比值 5.31x，落在脉冲比值区间 [5.17, 7.43] 内部
           ——任何阈值规则都必然牺牲一边。这是 triage.py「已知局限」注释
           （真实案例：2023-07 券商政策行情 5.4x vs 单位变更被稀释成 5.14x）
           的语料化。判别只能靠证据：量额一致性（va_shift ≈1 vs ≈4.6）、
           同窗口共振（peers 2 vs 0）。

三句话结论
----------
1. v2 同时做到根因 100% + 抑制 100%：它分开了规则分不开的混淆对
   （3 只合法放量脉冲全部正确抑制，规则与 v1 全部漏抑制）。
   这是「自进化产生超越规则引擎能力」的实测证据，也是 ROADMAP M13
   难例靶子要求的那份证明。
2. v1 的「根因 100%」是规则兜底撑起来的假象：10/16 条输出被拒收
   （模型自造 "P3" 级别），拒收即降级规则，规则兜底答对被记成了
   系统的正确。进化器把这个契约缺陷诊断了出来（五轮一致提议
   「级别取白名单」），维护者确认为 v1.1 契约修复基线。
3. κ 的正确读法：v2 与规则的根因 κ 只有 +0.5983——这不是坏事，
   恰恰说明 v2 在规则错的地方（放量脉冲）真实分歧；v1 时代
   κ=0.93 的「高一致」里有一半是拒收降级造成的假一致。

分级准确率诚实备注
------------------
v2 在 base 语料分级准确率 57.1%（4/7）：级别取值合法（不再自造 P3、
不再拒收）但不总等于标注期望（如个别 P0 判成 P1）。分级准确率自 M1 起
就不在进化适应度与门禁指标内（适应度 = 根因 + 抑制 + 精确），此处如实
报告不做粉饰；列入后续进化靶子。

进化过程（v1.1 出发，builtin 引擎，37 次调用 / 约 19.2 万字符）
--------------------------------------------------------------
[基线 v1.1] 训练集得分 57.1%（n=14，只给模型亲判条目记分）
[轮 1] 候选 78.6% / 78.6% —— 接受：否
       门禁退化：[extended] 误报抑制率 100% → 62.5%
[轮 2] 候选 85.7% / 85.7% / 85.7% —— 接受：是（第 3 候选）
       全量：根因 57.1% → 100%（extended 与 base 同时），抑制/精确不回归
[轮 3] 候选 85.7% × 3 —— 均未能严格胜过现任，收敛
关键机制（本轮实验迭代出的三条设计修正，各有单测）：
  a. 适应度只给「模型亲判且完全正确」的条目记分——否则拒收降级被
     规则兜底救回会记成成功，高拒收率反被奖励；
  b. Pareto 接受含「模型判定率」——规则兜底会掩盖模型真实变强，
     只看产品指标时进化在数学上不可能被接受；
  c. 严格改进只要求在目标语料（extended）上，对照语料（base）只要求
     零回归——要求 base 也严格更好等价于禁止一切针对难例的进化。

此前四轮探索性运行（v1 出发）如实记录：训练集得分一路爬升
（42.9% → 78.6% → 85.7% → 100%）但均未通过全量验收——它们撞上的
正是上面 a/b/c 三个设计缺陷，也是本次实验最值钱的副产品。

门禁
----
进化产物 eval-gate：extended + base 两语料 × 根因/抑制/精确三指标
全量不回归 —— PASS（接受时与独立复测各一次）。
独立复测（8 次调用）：v2 两语料 100/100/100，与接受时一致；
v1.1 抑制率在两次测量间波动（100% → 75%/60%），v2 无波动。
合入：v2 已提升为代码默认 prompt（与 eval/prompts/triage_v2.yaml
逐字节一致，CI 校验）；v1 原文在版本档案，可随时回滚。
