findata

数据质量监控 Agent。异常探测 → 根因归因 → 误报抑制 → eval 门禁。 不只是"找异常"，而是分辨"该告警"与"该忽略"，并在评测里立得住。

M1 数据层 M2 质量内核 M3 巡检流水线 M4 LLM 归因 M5 看板 M6 API + MCP + Docker

1探针观测

6 类探针独立工作：freshness / completeness / uniqueness / validity / drift / null_sweep。每类只答"观测到什么"，不带判断。

run_probes(ctx) → List[Finding]

2归因 + 抑制

规则归因器与 LLM 归因器可互换；不信任 LLM 原则下设计 （白名单校验、逐条降级、整批兜底），最坏不比规则差。

diagnose_all(findings, ctx) → List[Diagnosis]

3eval 先行

确定性合成语料 + 故障注入 + 5 项指标 + Cohen's κ 一致性。 CI 门禁把"归因层有 100% 增量"做成可证伪命题，不靠感觉。

run_evaluation(seed=…) → EvalReport

接入

POST /v1/inspect
跑一次巡检，返回 JSON 摘要与告警列表。支持 asof 回放历史时点。
POST /v1/eval
跑评测。triage=baseline/llm/both；both 输出 Cohen's κ。
GET /v1/dashboard
拉一份自包含 HTML 看板（无 CDN、无外部依赖）。
POST /v1/render
单日报告：fmt=md 或 html。

MCP Server

findata-mcp stdio transport，已被 Claude Desktop / Cursor / Cline 等原生支持。挂载到 MCP 客户端后，多出三个工具：

findata_health_check
跑一次巡检 → JSON 摘要。可传 asof / source / seed。
findata_dashboard
拼一份 HTML 看板，返回 html + length + summary 摘要。
findata_validate
跑评测 → 5 项指标；triage=both 时输出 Cohen's κ。
