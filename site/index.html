findata

可信数据增强模块。挂到成熟 Agent 项目上：宿主负责对话与编排， findata 负责回答「这个数字能不能引用、凭什么」——每个数字带 四档可信徽章，徽章可点开看归因证据链。

v2.0 带徽章可信日报 v2.1 增强模块（MCP/HTTP trust 接口） v2.2 通用包 trust-report eval 门禁 + 真实回放 golden

1探针观测

A 股领域包 7 类探针 + 通用包 5 类检查（完整性/唯一性/新鲜度/离群值/ Schema 一致），任意 csv/excel/duckdb/sqlite 表开箱即用。 每类只答"观测到什么"，不带判断。

run_probes(ctx) → List[Finding]

2归因 + 抑制

规则归因器与 LLM 归因器可互换；不信任 LLM 原则下设计 （白名单校验、逐条降级、整批兜底），最坏不比规则差。

diagnose_all(findings, ctx) → List[Diagnosis]

接入

POST /v1/inspect
跑一次巡检，返回 JSON 摘要与告警列表。支持 asof 回放历史时点。
POST /v1/eval
跑评测。triage=baseline/llm/both；both 输出 Cohen's κ。
GET /v1/dashboard
拉一份自包含 HTML 看板（无 CDN、无外部依赖）。
POST /v1/render
单日报告：fmt=md 或 html。

MCP Server

findata-mcp stdio transport，已被 Claude Desktop / Cursor / Cline 等原生支持。挂载后共 9 个工具——引用任何数字前先查 findata_trust_check（usable=false 不得作为已核验引用）：

findata_health_check
跑一次巡检 → JSON 摘要。可传 asof / source / seed。
findata_dashboard
拼一份 HTML 看板，返回 html + length + summary 摘要。
findata_validate
跑评测 → 5 项指标；triage=both 时输出 Cohen's κ。
findata_metric_query / findata_ask
可信问数：确定性 SQL + 交叉验证 + run_id 溯源 / 多智能体问答。
findata_trust_check / findata_trust_board
增强模块核心：单指标四档徽章+证据链 / 会话开始拉全板。
GET /v1/trust
HTTP 同源接口：给只能调 REST 的平台型宿主做引用门禁。
