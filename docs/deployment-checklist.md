# 公开部署前置清单（C2，只列不实现）

> 状态：**清单，不是待办**。当前产品定位是本机个人使用（无鉴权），公开部署
> 超出对外演示目的，除非所有者明确决定部署，否则不实现以下任何一项。
> 若决定部署，按序完成并逐项勾选后才可上线。

## 1. 鉴权与会话（未做，阻断级）

- [ ] 登录/注册（至少单用户口令；多用户则加会话管理）
- [ ] API 全端点鉴权中间件（`/api/*` 无匿名访问；`/healthz` 除外）
- [ ] 上传接口的 CSRF 防护（表单场景）

## 2. 限流与成本（未做，阻断级）

- [ ] 每用户问答频控（真实 API 调用，防刷 key——单用户如 20 次/日）
- [ ] 上传大小/频率限制（现有 50MB 单文件之上加日总量）
- [ ] token 日用量台账与硬顶（超顶熔断并提示）

## 3. 审计与日志（未做，阻断级）

- [ ] 提问与答案审计日志（谁、何时、问了什么、引用了哪些片段）
- [ ] 错误日志脱敏（PII 不进日志）
- [ ] 数据删除请求路径（用户可导出/删除自己的文档库）

## 4. 合规声明（部分已有）

- [x] 免责声明（前端答案卡固定行：不构成投资建议或法律意见）
- [x] 投资决策类问题拒答（C1，代码层）
- [x] 数据驻留说明（提问片段发往阿里云百炼，条款以服务商协议为准）
- [ ] 服务条款与隐私政策页面（公开部署必须）
- [ ] PII 脱敏默认策略裁决（当前默认关；公开部署建议默认开）

## 5. 基础设施

- [ ] HTTPS（反代终止 TLS）
- [ ] `findata_userdata/` 落盘加密或托管 KV（当前本机明文目录）
- [ ] 备份与恢复演练
