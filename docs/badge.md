# 可信徽章规范（v2.0 R1.2）

> 唯一权威实现：`src/findata/dq/badges.py`（映射与聚合）。
> 本文是产品口径的定义；代码与本文不一致时，先改代码再改本文，
> 或先改本文再改代码，但不允许长期共存两个口径。

## 一、四档徽章

| 徽章 | 含义 | 证据要求（可点开查看） |
| --- | --- | --- |
| ✓ 已核验 | 领域知识归因背书 | 归因结论 + 证据引用（`corporate_event` 事件 / 截面共动分布 / `index_daily` 指数量能 / 交易日历） |
| ✓ 基线通过 | 仅通用检查通过，无领域知识参与 | 检查项清单（新鲜度/完整性/唯一性/值域/漂移/空值/历史深度） |
| ⚠️ 仅借鉴 | 有疑点，人工判断 | 疑点描述（归因解释 + 观测值/阈值） |
| ✗ 不可用 | 归因为真实故障 | 根因 + 建议动作（来自告警路由） |

**诚实边界**（ROADMAP 第五节）：徽章必须如实区分「✓ 已核验」与
「✓ 基线通过」——前者有领域事实背书，后者只是"没查出毛病"。
对外表述不得把基线通过混同于已核验。

## 二、findings → (table, metric) → 徽章 映射规则

1. **行级信号覆盖全列**：缺失行/重复行/停更/历史深度不足命中
   `stock_daily` 时，该表全部 8 列（open/high/low/close/volume/amount/
   pct_chg/turnover）都受影响——缺的行会让每一列的聚合值都错。
2. **列级信号精确落列**：`pct_chg_out_of_limit → pct_chg`、
   `non_positive_volume / volume_recent_over_history → volume`、
   `high_lt_low → (high, low)`、`null_rate::<col> → <col>`、
   `total_mv_level_shift → valuation_daily.total_mv`。
3. **聚合取最坏**：一列上多条信号，活跃告警的 P0 → ✗、P1/P2 → ⚠️，
   压过一切 ✓；无活跃告警且存在被抑制的领域归因（BENIGN_*）→ ✓ 已核验；
   无任何信号 → ✓ 基线通过。
4. **未观测不发徽章**：表为空 = 探针什么都没查，不发徽章、不进健康分
   分母（可信分只对已观测事实归因）。

## 三、健康分口径（R1.2 验收定义）

```
score = 100 × Σ w(徽章) / 徽章总数
w: ✓ 已核验 1.0 · ✓ 基线通过 1.0 · ⚠️ 仅借鉴 0.5 · ✗ 不可用 0.0
```

- **由徽章聚合得出**，替代 v1.x 的「100 − 告警惩罚」口径；告警惩罚
  仍用于告警排序，但不再决定健康分。
- 与旧口径的对应关系：无告警 = 全 ✓ = 100；口径变化记录于 CHANGELOG
  v2.0.0。历史日报里的旧口径分数不可与新政直接对比。
- 只统计已观测表的列徽章（当前：`stock_daily` 8 列 + `valuation_daily`
  4 列 = 12 项）。

## 四、漂移归因的截面共动判据（R1.2 / 复盘 P0b）

漂移信号（`volume_recent_over_history`）先查同窗截面，再判故障：

| 判据 | 阈值 | 命中结果 |
| --- | --- | --- |
| 全市场共动 | 同窗 ≥ 半数可比标的放量 ≥2x **或** 指数量能 ≥1.5x | `benign_market_event` 抑制 |
| 板块共动 | ≥2 只同板块同伴放量 ≥2x（行业→板块映射见 `triage.py`） | `benign_market_event` 抑制 |
| 孤立事件 | 以上均不命中 | `distribution_drift` 保留告警（已知残留，待新闻事实源） |

阈值非拍脑袋：按 2026-09-15 复盘真实窗口实测标定——924 行情
24-25/25 标的 ≥2x + 指数 2.2-2.8x；724 行情全市场仅 6/25 但大金融
板块 3 只同伴 ≥2x；2023-03 中芯国际孤立事件同伴 ≤1.6x、指数 1.22x。
固化于 `eval/golden/replay.yaml` 真实回放门禁。

## 五、知识层状态行（R1.0 / 复盘 P0d）

日报头部固定展示：`corporate_event` 行数 + 最新事件日期。事件表为空时
显式降级提示「停牌/除权归因无事实可依，该类误报无法抑制」——抑制能力
降级必须对值班的人可见，不允许以"降噪 0%"的形式无声出现。
