30 秒看懂这个系统

把你的金融长文档——法规、财报、保险条款、募集说明书、研报—— 变成一个「可以提问」的知识库：上传文档，用大白话提问，得到带出处引用的答案。 它只依据你的文档回答，文档里没有的会明说，不编造。

三步上手

1
上传文档 回到「我的文档」标签页，点击虚线框选择文件，或直接把文件拖进去。支持 PDF、Word、TXT、Markdown。
2
用大白话提问 在下方输入框里像问同事一样问，例如「违约金比例是多少」「这笔担保需要股东大会通过吗」。
3
核对答案与出处 每条答案都标注来自哪份文档的哪个章节；点「出处」可以核对原文。答案与出处对不上就不该采信。
第一次用？建议先传一份 10 页以内的 PDF 练手，问一个你确定文档里有答案的问题， 感受一下「答案 + 出处」的形态。

它擅长什么、不擅长什么

擅长：在长文档里找条款、对数字、核结论—— 「第几条说了什么」「这个数字是多少」「研报的结论和正文数据一致吗」这类问题。 支持中文与英文文档（英文财报/10-K 检索经过 FinanceBench 外部基准校准）， 扫描件（图片型 PDF）自动走本机 OCR；答案用与提问相同的语言作答。

不擅长 / 不做（会如实说，不硬答）：

  • 文档里没有的信息——系统不会替你上网查，也不会用常识补，只会回答「未提及」；
  • 投资决策建议（该不该买 / 目标价 / 选股）——直接拒答并转引客观事实， 这是有意的产品边界，不构成投资建议或法律意见；
  • 英文域检索仍弱于中文条款域（recall@8：英文 16.2% vs 中文评测 98%+ 口径不同仅示意）， 复杂英文题建议拆小了问；
  • 跨文档的复杂推理可能需要你把问题拆小、分次问。

费用与隐私（如实边界）

  • 每次提问是真实大模型调用：自由问答约 10–30 秒、评测题约 1–2 分钟， 花的是你配置的阿里云百炼 API key 的钱（单次几分钱量级）；
  • 文档原件与检索索引只存在你本机 findata_userdata/（已 gitignore）； 提问时，与问题相关的文档片段会发送给阿里云百炼（中国大陆节点）生成答案—— 数据驻留与服务商数据处理条款以阿里云百炼服务协议为准；
  • 上传时可勾选 PII 脱敏：身份证 / 手机号 / 邮箱 / 银行卡形态数字在 检索文本中打码（原件不动）；扫描件 OCR 在本机 CPU 推理，图片不出本机；
  • 本演示无登录鉴权，只在本机使用，不要暴露到公网。

常见问题

支持哪些文件格式？有大小限制吗？
PDF、Word（.docx）、TXT、Markdown，单个文件 ≤ 50MB。 扫描件（图片型 PDF）自动走本机 OCR 提取（需安装可选组件： uv sync --extra ocr；未安装时会在文档里明确标注原因， 不会静默给空文本）。PDF 里的表格会自动还原为结构化表格。
问「该不该买」为什么不回答？
这是有意的产品边界：系统做的是文档信息整理， 不是投资建议。买卖、仓位、目标价这类决策建议会被直接拒答（不发模型 调用），并提示你改问客观事实（如「文档披露的营收是多少」）。 投资决策请咨询持牌投资顾问。
为什么有时回答「文档中没有提及」？
这是有意设计：系统只依据检索到的文档片段作答， 证据不足就明说，不靠模型记忆编一个像样的答案。对金融文件来说， 「宁可不答，不能编造」比「什么都答上来」更有价值。
为什么要点十几秒甚至一两分钟？
因为每次都是真实的大模型调用：先检索相关段落，再逐项判定 / 生成答案， 最后核对引用出处。页面上的按钮会显示已等待时间，请勿重复点击。
「评测演示」和我上传的文档有关系吗？
没有。评测演示用的是仓库自带的 50 道题 + 7 份官方原文（法规 / 财报 / 保险条款 / 债券募集说明书 / 研报），用来展示系统的证据链与判定过程； 你上传的文档只在「我的文档」里使用。
报错「缺少 DashScope API key」怎么办？
在项目根目录的 .env 文件里配置 FINDATA_DASHSCOPE_API_KEY=你的key（阿里云百炼控制台可申请）， 然后重启服务：uv run findata-finqa-app。
想删掉某个文档？
在「我的文档」的文档库里点「删除」，会同时移除原件与索引， 之后提问不再引用它。

系统是什么

金融长文档（法规 / 财报 / 保险条款 / 债券募集说明书 / 研报）问答系统，四层全链：

检索（条款级分块 + BM25F 双通道字段加权 + B 榜两阶段） → 判定（每个选项只用自己召回的证据独立三态判定，代码确定性拼装答案） → 记忆（朴素滚动摘要 / 分层压缩双臂） → 归因（引用观测：只统计匹配到在场内容的引用，防幻觉虚增）。

评测集：50 题 / 7 份官方原文文档（含 193 页募集说明书）/ 五域。 当前读数：隔离判定臂 98%–100%，token 全程台账。

错题形态迭代链（核心资产）

每一环：错题形态 → 机制根因 → 修法 → 归档读数 → 回归测试。 另有三次「走错又折返」同样留档（长度归一化反噬 / 复审干扰 / 测试配置分叉）。
