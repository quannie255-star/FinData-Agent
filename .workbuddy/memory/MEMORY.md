## 1. 主线读数（引用前先看效力边界）

**最强臂 = 选项级证据隔离**：脚手架 v4 基线 k4 **49/50 = 98%（453,329 token）**；M2.5 两阶段检索把
B 榜 7 题复测 **7/7** ⇒ **隐含全量 50/50**。官方 baseline（全文直入）**A 49% / B 13%** ⇒
**B 榜检索是最大失分点，检索优先于压缩**（准确率主导，token 系数只在 [0.7, 1.0]）。

四条可引用结论：
1. **压缩的代价能被定位**：朴素滚动摘要 **23/31 = 74.2%（token 反增 12%，两轴皆输）**；8 错题里
   6 道因判定对某选项 UNCERTAIN 被保守规则漏选（摘要丢了精确细节）。
2. **分层压缩验证「不可逆信息不动」**：数值/条款逐字 + 只压叙述 ⇒ **96%（612K token）**，
   较纯摘要**恢复约 19pp**；但 token 仍高于不压缩的检索臂 ⇒ **帕累托前沿未变**。
3. **引用观测（防幻觉引用虚增）**：isolate 使用率 29.85%、浪费 56.35%，**位次曲线 73/24/20/8%**
   —— 第 4 位近死重，但某错题的表格块恰在第 4 位 ⇒ **"砍尾部"不能直接翻译，必须配对验证**。
4. **长链架构放大非确定性**：memory n=3 = **74.2 / 80.6 / 77.4%（±3.2pp）**，isolate 逐配置确定
   ⇒ **质量结论必须带区间或注明 n**。

**英文域检索三臂消融（2026-10-10，FinanceBench 99 题，归档 `examples/financebench-recall-v3/`）**：
recall@8 纯 BM25F 16.16% → 纯向量 **41.41%**（recall@16 25.25%→55.56%）；**等权 RRF 混合反弱于
纯向量**（21.21%）⇒ **杠杆是向量臂本身，不是融合**；answer@8 三臂同为 37.37%（k=8 上下文已大到
答案常在）⇒ **单看 answer@8 会漏掉检索差异**；§3.1.1 门禁（≥50%）**未达**。bm25 臂与 v2 逐位一致；
hybrid `embed_calls=0`（缓存命中）。**产品口径，违反赛题四「禁 embedding」，对外引用须注明差异。**

**效力边界**
- **分辨力下限 `2^(1-k)`**（k = 配对不一致对数）：**k ≥ 6 才可能有分辨力**（k<6 时最小 p ≥ 0.0625）
  ⇒「不显著」只能读成「**本对照测不出**」，既非"无差异"也非"等效"；**报不显著必须同时报 k**。
  M5 k 阶梯 k4 31/31(192,748) / k3 30/31(170,705) / k2 31/31(159,918, −32.8%)：**±1 题低于分辨力，
  token 差是结构性确定值**；k=2 记候选默认，切换需 50+ 题支撑（**不擅自改**）。
- **题量 = 分辨力天花板**：20/20 时区分度耗尽 ⇒ **先加难度，再谈优化**。
- v4.0 遗留三条边界：`-fz`(214 文件含答案卡) 与 `-fx`/`-fp`(210 无卡) **是两个语料不可混用**；
  7B `-fp` 批**内部分裂**（两组代码指纹）⇒ 7B 的 R5.2 **只有 `fx↔ch` 一格能用**；
  **解码仍未固定**（无 seed）⇒ 顺序定死 **①先量噪声下界 → ②再固定解码 → ③才写进对照表**，不许颠倒。

## 2. 铁律（每条都是真事故换来的；通用做法已沉淀成 skill）

**2.1** ① **证据强度要分层：「值缺失」与「值放错位置」差一个量级**（`permitivity` 声称默认
8.854e-12 却无 default，该值**标在 int 型 `charge`/`distance` 上** ⇒ 不是"漏标"是"错位"）
⇒ **处置由证据强度决定，不按类别一刀切**：漏了→补上、放错了→移动。
② **两种解释都成立时选可逆的动作**，别打解释之争（判据：**丢样本不可逆、改 schema 可逆** ——
1 处缺陷影响 258 条样本：修 1 处消 258 条歧义，丢 258 条什么都不解决）。
③ **报数前先问：这个"冲突"是不是数据源的表示层约定**（2162 命中探针核出该源 89.1% 的 `default`
本就是字符串 ⇒ **探针当场删除**）——**一个从不删规则的质检系统，指标只可能虚高**。

**2.2 措辞**：五档处置 `✓ / ⚠️ / ✗ / ⊘ / 🔧 待修 schema`（第五档 = 根因在数据源，处置作用回数据源）；
选择还看 ①能否给出可执行动作 ②**队列长度**（349 条时逐条看等于没有队列 ⇒ 必须结构性修复）。
「命中率」≠「发现率」；**命中数 ≠ 错误数**；「未命中」≠「干净」（无执行反馈时"正确"观测不到）；
**口径写进产物本身**（`manifest.note`），别只活在文档里。

**2.3 门禁与可复现**：`tests/test_docs_consistency.py` 钉「各文档测试数 == `pytest --collect-only`
真实数」（错数 354 曾在 6 处共存一个月）。**可复现三元组** = `code_commit` + `rules_version`
（改判定逻辑必须动 `triage.RULES_VERSION`）+ `data` 指纹；账单 `code_commit` 取自语料根 ⇒ 补
`executed_code`；**相对路径是指纹的一部分**。

**2.4 对照实验元坑（同一个错误犯过三次）**：patch 错函数 / 漏 `--model` / 边跑边改仓库
⇒ **"只有一处不同"必须由产物核对**；核对五样：**代码指纹 · 模型 · 语料指纹 · 工具清单 · 裁剪策略**。
**臂名是标签不是证据**（文件名会撒谎）；`--require-same-corpus` / `--require-same-code` 不一致即 **exit 2**。

**2.5 冻结由路径保证，不靠自律**（`git worktree` + `--corpus-root`）；**一句声明必须有产物能证伪它**，
否则是口号。**盲区要写出来**：说「已核 4 处、未核的不知道」，不说「只漂了 4 处」；报漂移同时报**方向**。

**2.6 指纹必须测"工具实际读到的东西"**：字节哈希把 CRLF 差异**误报 53 个文件**，改成"归一化文本
哈希 + 规模按字符数"后 **53 → 0** ⇒ **先分清表示层差异，再谈内容差异**（Windows `Path.write_text`
会把 `\n` 翻成 `\r\n`；测试构造 CRLF 必须用 `write_bytes`）。

**2.7 同一文件的并行编辑会互相覆盖**：同一条消息里给同一文件发两处 Edit，第二处按旧内容匹配
⇒ **一处静默丢失** ⇒ **改同一个文件必须逐个发**。

**2.8 判据泄漏两个面**：答案侧指纹**取窄**（**一个"泄漏"标记会直接剔数据，误标就是误删**）；
语料侧三条判据（路径 / **内容——实测抓到路径清单漏掉的 2 个文件** / 重放）。
**教训：知道了泄漏 ≠ 处理了泄漏** —— 判别澄清的一半，必须配一次「**换干净输入重算**」。

**2.9 代码指纹会把"边跑边改"印出来**：`--corpus-root` 冻不住被执行的代码 ⇒「变化的轴」必须由
`describe_axis()` **从账单逐字段推导**，不许硬编码进标题；**缺字段一律读作「未记录」，不许顶成 0**。

**2.10 `--basetemp` 复用 → 143 个假错误级联**（沙箱 safe-delete 守卫拦 `rm_rf` ⇒ SystemExit 落
fixture setup ⇒ 级联）⇒ **报错数 ≠ 缺陷数**；`mktemp -d` 给 `/tmp/...`，传给 Windows 程序前必须过
`cygpath -m`。

## 3. 缺陷与诚实边界

**对外报数三条**：① **token 只占可变运行成本 20–25%**（人工复核 70–75%）⇒ 别把"省 25% token"
说成"省 25% 钱"；② 机制层（找没用过的工具 / 少发定义 / 检索注入 / 成本面板）**已全部商品化**；
③ 结论限定**本机 7B/3B** 口径 —— token 侧可迁移、成功率侧不可。

**面试四个"承认"**：① 人工一致性 κ **没做**（只有机器 vs 机器 κ=+0.7417, n=13）；② 超时归因只有
一个信号且**刻意不修**；③ held-out 63.6% vs 门禁 ≥0.9 的**红灯不划掉**；④ 7B 质量侧只剩一格。

**竞品 Jev 折扣版**：独立审计实测 **5–25×**（非宣传 20–400×）、**概率校准无公开曲线 = 没法验证**、
`fast-jev-compaction` 把工具结果换成一行提示 ⇒ **判的是合理性不是证据** ⇒ 缝隙只剩两样且必须靠
实测站住：**① 证据来自 trace 的引用观测 ② 有配对验证闭环**。不把闭源付费 API 接进 CI。

**v3.0 领域包**：60000 条 / 100011 次调用 / 命中 1351（2.25%）/ A 侧 65 / B 侧 1286 / 21 工具 21 参数 /
**丢弃 0**；核心命题「**形态相同、结论相反**」。

**其它已知缺陷**：3605 个工具名里 **296 个（8.2%）有多份互不相同的定义**（`search` 77 种）⇒
"任一份 schema 能解释就放行"在百万级会**系统性少报**。`corporate_event` 曾是空表（有 schema +
消费方、**无采集代码**）⇒ 停牌抑制规则全失效、真实告警 7/7 误报；R1.0 已修，
**改抑制逻辑前先看 `docs/reviews/2026-09-15-attribution.md`**。
