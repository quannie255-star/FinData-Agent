## M10 收尾：docker release 链路打通（d81b08a）

**问题**：release workflow 连挂 5 轮（4b885a6 / 8c4e804 等），全卡在

- builder 只 `uv sync --no-dev --no-install-project`（这步一直是通过的）
- runtime 只拷 `/build/.venv/lib/python3*/site-packages/` 进系统

- project 走 `/app/src` + `PYTHONPATH` 直跑；`findata.__version__` 有
  `_FALLBACK_VERSION` 兜底（镜像里没有 installed metadata）
- Dockerfile 加 build-time 冒烟：`import findata` + `site/index.html` 存在

**release.yml 加 push 前门禁**：先单架构 amd64 `--load` 构建 → `docker run`
→ curl `/healthz` 与 `/`（`trap 'docker logs ...' EXIT` 保证失败也有日志）
→ 通过后才 multi-arch push。**坏镜像绝不进 ghcr.io**。

**版本统一 0.4.0 → 0.5.0**：pyproject / uv.lock(findata 条目) / docker-compose
image tag / `__init__.py` 兜底常量；`tracing.setup_tracer` 的
